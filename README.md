# AgentOps — Enterprise Agentic Procure-to-Pay Platform

**P2P AgentOps** — an AI-powered Procure-to-Pay operations platform where
specialised agents process invoices, resolve exceptions, accelerate approvals,
engage suppliers, optimise payments and predict SLA risk — with a human
decision required at every stage.

Implementation lands via pull request. See `RUNNING.md` for local setup once
merged.
